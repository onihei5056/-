# 筋トレ記録

週1回のシーテッドマシン中心トレーニングを最小の手間で記録するアプリ。
データはブラウザの localStorage(キー `workout-log`)に保存。ログイン・外部通信なし。

## 使い方(記録は3タップ＋数値調整)
1. ホームで「下半身 / 上半身 / 全身」を選ぶ
2. 推奨重量・前回repが入った状態で、必要な数値だけ ± で直す(やらない種目はチェックを外す)
3. 体感(楽だった / ちょうどいい / きつかった)を選んで「記録する」

## ルール
- 進行:前回全セット12rep達成 → +5kg(レッグプレスのみ+10kg)。未達は据え置き
- 重量を上げた回はrep初期値を10に戻す(未入力のまま保存しても連続で重量が上がらないように)
- 連続週数:月曜始まりの週単位。1週空き=保留、2週空き=リセット
- ふりかえりは記録データの比較のみから生成(良かった点1〜2行 / 気になった点0〜1行 / 次回1行)

## 開発
```
npm install
npm run dev
npm run build   # dist/ に出力(相対パスなのでどこに置いても動く)
```
ロジック・画面・スタイルは `src/App.jsx` 1ファイルにまとめている。
