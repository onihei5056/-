# 画面遷移図

```mermaid
flowchart TD
  A[案件一覧] -->|新規調査の作成| B[新規調査の作成]
  A -->|案件をタップ| C1
  A -->|サンプル案件を作成| C1
  B -->|作成して入力開始| C1

  subgraph 入力ステップ(全11ステップ・戻る/一時保存/次へで移動)
    C1[3 物件基本情報] --> C2[4 売主および権利関係]
    C2 --> C3[5 法務局調査]
    C3 --> C4[6 役所調査]
    C4 --> C5[7 道路・用途地域・建築制限]
    C5 --> C6[8 上下水道・電気・ガス]
    C6 --> C7[9 周辺環境]
    C7 --> C8[10 設備現況写真]
    C8 --> C9[11 擁壁調査]
    C9 --> C10[12 入力内容確認]
    C10 --> C11[13 PDFプレビュー]
  end

  C10 -->|エラー項目をタップ| C1
  C10 -->|エラー項目をタップ| C9
  C11 -->|保存して一覧へ戻る| A
  C11 -->|再出力/印刷/共有/端末へ保存| C11

  A -->|設定| S[設定画面]
  S -->|案件一覧に戻る| A
```

- 各入力ステップは「戻る」で前ステップへ、「次へ」で次ステップへ遷移します(`app/src/schema/flow.ts`)。
- 「入力内容確認」でエラー(修正必須)がある場合は各項目をタップすると該当画面へジャンプします。
- 「PDFプレビュー」から「保存して一覧へ戻る」を押すと案件一覧に戻ります(この時点でPDF未保存でも案件は自動保存済みです)。
- 案件一覧はいつでも `案件一覧` ボタンで戻れます(画面上部)。
