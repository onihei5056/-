# iPhone、Android、PCでの確認ポイント

## iPhone(Safari)

- ホーム画面追加: 共有ボタン→「ホーム画面に追加」。初回訪問時に案内バナーが表示されるか。
- スタンドアロン起動時にSafariのアドレスバーが表示されず、アプリらしい見た目になっているか。
- カメラ起動: 「📷 カメラで撮影」タップ時にカメラアプリ(写真/ビデオ選択ダイアログ)が開くか。
- PDFプレビュー: `<iframe>` 内にPDFがプレビュー表示されるか(SafariのPDFビューアはOS標準のものが使われます)。
- 共有: 「共有」ボタンでシェアシートが開き、AirDrop/メール等に送れるか(`navigator.canShare`対応状況に依存)。
- セーフエリア: ノッチ/ホームインジケーター付近でボタンが隠れていないか(`env(safe-area-inset-bottom)`対応済み)。

## Android(Chrome)

- インストールバナー: `beforeinstallprompt` を捕捉したインストールバナーが表示され、インストールできるか。
- ホーム画面アイコンから起動した際にスタンドアロン表示になっているか。
- カメラ起動: `capture="environment"` によりバックカメラが直接起動するか(機種により選択ダイアログが出る場合あり)。
- PDFプレビュー: Chromeの標準PDFビューアがiframe内で機能するか。
- 共有: Web Share API (`navigator.share`) でファイル共有ができるか(Android Chromeは概ね対応)。
- 戻るボタン: Android物理/ジェスチャーの「戻る」でアプリ内履歴が破綻しないか(HashRouterの履歴スタックを確認)。

## PC(Edge / Chrome / その他モダンブラウザ)

- レスポンシブ: ウィンドウ幅を狭めてもモバイルレイアウト(最大幅720pxの中央寄せカラム)が崩れないか。
- PDFプレビュー: Edge標準のPDFビューアでiframe内プレビューが表示されるか。印刷(Ctrl+P相当のボタン)が機能するか。
- ファイル選択: 「写真から選択」でファイル選択ダイアログからPC内の画像を選べるか(カメラボタンはPCでは通常ファイル選択にフォールバック)。
- インストール: Edge/Chromeのアドレスバーのインストールアイコンからデスクトップアプリとしてインストールできるか。

## 共通確認事項

- 日本語表示がすべての画面・PDFで文字化けしていないか(フォントはOS標準の日本語フォントに依存するため、
  各OS・ブラウザで目視確認してください)。
- オフライン切り替え(機内モード)後もアプリの基本画面が表示され、入力中データが失われないか。
- 画面回転(縦→横)時にレイアウトが大きく崩れないか(主要利用は縦持ち想定)。
