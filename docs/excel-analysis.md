### 重要な発見(要確認)

- 現行版シート `不動産調査シート2026.3.1` は **役所調査から始まっており、売主・面談情報／物件情報／法務局調査を含みません**。
  これらは非表示の旧版シートにのみ存在します。
- 逆に、**マンション調査事項は現行版にのみ**存在します(旧版にはありません)。
- **地盤補強は旧版にのみ**存在し、現行版では削除されています。
- したがって本アプリは「現行版シート ＋ 旧版シートの前半(売主〜法務局)＋旧版の地盤補強」を合成した構成としています。
  この合成方針の可否は `docs/open-issues.md` の要確認事項に記載しています。

### 数式・入力規則・コメント

全4シートとも **数式0件・入力規則(ドロップダウン)0件・セルコメント0件** です。
帳票はすべて「□チェックボックス＋全角スペースの記入欄」で構成された手書き前提のテキストです。
建ぺい率・容積率・延床面積合計も数式ではなく記入欄(`■本物件の建ぺい率：建築面積÷敷地面積＝　　%`, `合計:　㎡`)でした。
アプリではこれらを自動計算項目として実装しています(下記「計算項目一覧」)。

## 4. 写真項目一覧

### 設備現況写真シート

元Excelの写真枠は6つ(A5:E14, F5:J14, A17:E26, F17:J26, A29:E38, F29:J38)で、それぞれ
**【上水道】【メーター】【汚水】【雨水】【ガス】【電気】** のラベルが付いています。
さらに K・L列に撮影上の注意事項が【上水】【下水】【浄化槽】【雨水】【ガス】について記載されています。

アプリでは6枠をそのまま区分として実装し、注意事項に登場する **下水・浄化槽**、および **その他設備** の
区分を追加しています(追加分は帳票枠外であることを画面に明示・要確認)。注意事項は原文のまま写真登録画面に表示します。

その他、同シートには以下が含まれます。

- 撮影日(C40) / 撮影者(H40) … アプリでは写真ごとの撮影日時・撮影者から自動集計してPDFに出力
- 共通注意(K4,K5,K40,K41) … 「写真撮影は受託時が基本です…」「※契約審査時、枠内に収まらない場合は別途写真を添付する」「※上下水の引込が共有の場合は…」
- 免責文(A42) … 築年数を差し込む文面。アプリでは案件ごとに築年数を入力してPDFへ反映

## 6. 計算項目一覧

元Excelには数式がなく「記入欄」でしたが、アプリでは自動計算にしています(自動計算値は点線枠で表示し、「手動修正」ボタンで上書き可能・修正状態を記録)。

| 項目 | 計算式 | 元Excel | 備考(Excelの注記) |
|---|---|---|---|
| 延床面積 合計 | 地階延面＋1F延面＋2F延面＋3F延面 | 旧版!I15,J15 | - |
| 本物件の建ぺい率 | 建築面積 ÷ 敷地面積 × 100 | 2026.3.1!B17 | ※1Fより2Fの面積が広い場合は2F面積で算出 |
| 本物件の容積率 | 延床面積合計 ÷ 敷地面積 × 100 | 2026.3.1!B18,B19 | ※前面幅員4m未満の場合は4mとみなし算出 ※増築未登記がある場合は増築後の面積で算出 |

セクションをまたぐ参照(建ぺい率は「役所調査」画面、敷地面積は「売主・面談情報」画面)に対応するため、
計算項目は `sectionId.fieldId` 形式で他画面の値を参照できます(`app/src/utils/calc.ts` の `buildGlobals`)。

また入力チェックとして、計算値が指定建蔽率・指定容積率を超えているのに「建ぺい超過/容積率超過=有」が
選択されていない場合に警告を出します。

## 7. PDF構成案(実装済み)

元Excelの3帳票をこの順で出力します。

1. **不動産調査シート**
   - 案件情報(案件名/所在地/調査日/担当者/PDF作成日時)
   - 大分類ごとの見出しバー ＋ 中分類ごとの項目表(項目名列＋記入列の2列構成)
   - 選択項目は元Excel同様 **☑/☐ で全選択肢を印字**
   - 末尾に脚注 ※1〜※20(旧版シートA88の原文)
2. **設備現況写真**
   - 共通注意事項 → **2列×3行の写真グリッド**(元Excelと同じ配置)
   - 各枠に区分名・撮影日時・撮影者・コメント
   - 撮影情報(撮影日/撮影者)→ 免責文(築年数差し込み)
3. **擁壁調査シート**(擁壁ごとに繰り返し)
   - 基本情報 → 許認可(根拠法令別の許可・検査済証) → がけ → 不適格・不具合箇所(☑/☐) → 備考
   - 写真(敷地図・撮影方向 / 全景 / 不具合箇所)を2列グリッドで出力
   - 末尾に免責文(AC44の原文)

全ページ共通で、ヘッダーに案件名・所在地、フッターに作成日時とページ番号を出力します。
写真は1ブロック=1行(2枚)単位でページに詰めるため、写真が改ページで分断されません。
