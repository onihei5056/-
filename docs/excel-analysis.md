# Excel分析結果

## 重要な前提(必読)

本タスクの開始時点で、元となるExcelファイル「不動産調査シート_2026.3.1.xlsx」の実体がセッションに
提供されませんでした(作業ディレクトリ・Gitリポジトリ・Google Drive等いずれにも存在せず)。

ユーザーに確認したところ、「ファイルなしで一般的な様式で進める」との回答を得たため、本アプリは
**一般的な不動産現地調査シートの標準様式を仮定義**して実装しています。

したがって以下は「Excelを解析した結果」ではなく、**一般的な業界標準を踏まえた仮の分析結果**であり、
全項目が要確認対象です。実際のExcelが提供された場合は、下記の各章を実ファイルの内容で置き換え、
`app/src/schema/sections.ts` 等のコードを実データに合わせて修正してください。

---

## シート一覧(仮)

| No | シート名(仮) | 内容 | 本アプリでの対応画面 |
|---|---|---|---|
| 1 | 不動産調査シート | 物件基本情報〜周辺環境までの現況調査全般 | 物件基本情報〜周辺環境(7画面) |
| 2 | 設備現況写真 | 上水道・メーターボックス・汚水・雨水・下水・浄化槽・ガス・電気・その他設備の写真台帳 | 設備現況写真 |
| 3 | 擁壁調査シート | 擁壁の許認可・工法・不具合等の詳細調査(複数擁壁対応) | 擁壁調査 |

## 大分類一覧(仮)

「不動産調査シート」相当を以下の7画面・44中分類相当に整理しました(詳細は `docs/item-definitions.md`)。

1. 物件基本情報(物件基本情報／地番・家屋番号・住居表示／建築年月日／土地・建物の面積／評価額／境界明示／マンション調査事項)
2. 売主および権利関係(面談情報／登記名義人の現況／売却理由／空家期間・従前の利用方法・管理状況／引越先・退去時期／残置物／第三者占有／契約不適合・見積依頼／保管書類)
3. 法務局調査(登記記録)
4. 役所調査(役所調査／取得書類)
5. 道路、用途地域、建築制限(計画道路／用途地域・地域地区／建蔽率・容積率／道路種別・前面道路等／高さ制限・土地区画整理法・その他法令)
6. 上下水道、電気、ガス(飲用水／電気／ガス／太陽光／汚水・雑排水)
7. 周辺環境(周辺環境／コンクリートブロック／擁壁・がけ条例・地盤補強／町内会・ゴミステーション／隣家訪問)

擁壁が「有」の場合、別途「擁壁調査」画面(複数追加可)が入力対象になります。

## 項目定義

`docs/item-definitions.md` を参照してください。シート名・大分類・中分類・項目名・入力方式・
必須／任意・単位・選択肢・入力制限・条件分岐・写真の要否・備考・PDF表示区分・要確認フラグを
全項目について一覧化しています(`app/src/schema/sections.ts` から自動生成)。

## 写真項目一覧

設備現況写真は9区分(上水道／メーターボックス／汚水／雨水／下水／浄化槽／ガス／電気／その他設備)。
各区分の撮影上の注意事項は `app/src/schema/sections.ts` の `PHOTO_CATEGORIES` および
写真登録画面(EquipmentPhotosPage)の注意書き表示に反映しています。詳細は `docs/item-definitions.md` の
「設備現況写真区分」章を参照してください。

## 条件分岐一覧

要件で明示された8パターンをすべて実装しています(`app/src/schema/sections.ts` の `condition` プロパティ)。

| 条件 | 表示される項目 |
|---|---|
| 計画道路=有 | 計画決定、事業決定、名称、幅員 |
| 道路種別=私道 | 通行許可の有無、掘削許可の有無 |
| 擁壁=有 | 擁壁調査画面が入力対象に追加(周辺環境画面に注記) |
| ガス種別=LPガス | LPガス会社名、連絡先 |
| 排水方式=浄化槽 | 集中／個別、合併／単独、管理会社、連絡先 |
| 第三者占有=有 | 占有の種類(賃貸借／使用貸借)、契約期間、氏名、住所、契約書の有無、滞納の有無 |
| 残置物=有 | 売主処分／現況渡しの選択欄、内容 |
| 太陽光=有 | 搭載容量、契約期間、売電単価 |

上記以外にも、マンション調査事項(物件種別=区分マンションの場合のみ表示)、空家関連項目(空家の有無に連動)等、
妥当性の高い分岐を追加で実装しています。詳細と表示条件の式は `docs/item-definitions.md` の「条件分岐」列を参照してください。

PDF出力時、条件により非表示となった項目は原則として「-」(空欄相当)で出力し、元帳票の行構成(見出し・行順)を崩さないようにしています(`app/src/pdf/generator.ts` の `fieldValueText`)。

## 計算項目一覧

| 項目 | 計算式 | 実装 |
|---|---|---|
| 延床面積合計 | 地階＋1階＋2階＋3階以上の床面積の合計 | `calc.kind = 'sum'` |
| 建蔽率(実際) | 建築面積 ÷ 敷地面積 × 100 | `calc.kind = 'ratio'` |
| 容積率(実際) | 延床面積合計 ÷ 敷地面積 × 100 | `calc.kind = 'ratio'` |

いずれも自動計算値であることが分かるよう専用の表示(点線枠+「手動修正」ボタン)にしており、
手動修正した場合は `manualOverride` フラグで記録されます(`app/src/hooks/useSectionAnswers.ts`、
`app/src/components/FieldInput.tsx`)。

## PDF構成案

1. 表紙(案件情報: 案件名・所在地・調査日・担当者・PDF作成日時)
2. 各セクション(物件基本情報〜周辺環境): 大分類ごとに見出しバー＋中分類ごとの項目表
3. 設備現況写真: 区分ごとに見出し→写真1枚ずつ(撮影日時・撮影者・コメント付き)を1ブロックとして配置し、ページ送り時に写真が分割されないようビンパッキング配置
4. 擁壁調査: 擁壁ごとに項目表→写真(全景・不具合箇所)
5. 各ページ共通ヘッダー(案件名/所在地)・フッター(作成日時・ページ番号)

実装は `app/src/pdf/generator.ts`、`app/src/pdf/blocks.ts` を参照。
