## 実機・実環境での実施を推奨するテスト(未実施・チェックリスト)

### 機能テスト

- [ ] 必須項目未入力のまま「次へ」を押した際に確認ダイアログが出ること
- [ ] 数値項目に不正な値(文字列等)を入力できないこと(type=number制約)
- [ ] 日付の逆転(空家開始日が調査日より後)でエラーになること
- [ ] 擁壁「有」なのに擁壁調査未登録の場合にエラーとなること
- [ ] 不具合箇所を登録したのに写真未登録の場合にエラーとなること
- [ ] 建蔽率・容積率の自動計算値が手動修正でき、「自動計算に戻す」で復元できること
- [ ] カメラ撮影・ギャラリー選択の両方で写真登録できること(実機カメラ使用)
- [ ] 写真の回転・並び替え・削除・撮り直し・PDF掲載切替が保存されること
- [ ] 案件の複製で写真・擁壁調査を含めて複製されること
- [ ] 案件削除で写真・入力内容も削除されること
- [ ] 検索(案件名・所在地・調査日・担当者)が正しく絞り込まれること

### オフライン・永続化テスト

- [ ] 機内モードで新規入力・写真登録ができ、通信復旧後も内容が消えないこと
- [ ] ブラウザを閉じて再度開いても、一時保存済みの入力内容が復元されること
- [ ] 画面をリロード(スワイプ更新含む)しても保存済みデータが消えないこと

### PWAテスト

- [ ] iPhoneでホーム画面に追加し、スタンドアロン表示(Safari UIなし)で起動できること
- [ ] Androidでホーム画面に追加し、スタンドアロン表示で起動できること
- [ ] オフライン状態でアプリを起動し、基本画面が表示されること(初回オンライン訪問後)
- [ ] アプリ更新後、次回起動時に「新しいバージョンがあります」通知が出て更新できること

### PDFテスト

- [ ] iPhone SafariでPDFプレビュー・保存・共有ができること
- [ ] Android ChromeでPDFプレビュー・保存・共有ができること
- [ ] PC EdgeでPDFプレビュー・印刷ができること
- [ ] 大量の写真(20枚以上)を登録してもPDF生成が完了し、写真が欠落しないこと

### セキュリティテスト

- [ ] PIN未設定時は誰でも操作できること(意図した挙動)、PIN設定後は再認証が要求されること
- [ ] 15分放置後に自動ロックされること
- [ ] 案件削除・写真削除に確認ダイアログが表示されること
