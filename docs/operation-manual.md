# 操作マニュアル

## 1. ホーム画面への追加

### iPhone(Safari)
1. Safariでアプリを開く
2. 画面下部の共有ボタン(四角から矢印が上に伸びるアイコン)をタップ
3. 「ホーム画面に追加」を選択
4. 初回起動時に案内バナーが表示されます。「今後表示しない」を押すと以後表示されません。

### Android(Chrome)
1. Chromeでアプリを開く
2. 画面下部に表示される「アプリをホーム画面に追加」バナーの「インストール」をタップ
   (表示されない場合はChromeメニュー→「アプリをインストール」)

## 2. 案件を作成する

1. 案件一覧画面で「＋ 新規調査の作成」をタップ
2. 案件名・物件所在地(必須)、調査日・担当者を入力し「作成して入力開始」

## 3. 現地調査を入力する

1. 「物件基本情報」から順に、大分類ごとのカードに沿って入力します
2. 画面上部に現在のステップ・全体進捗率・保存状態・未入力必須項目数が表示されます
3. 「有／無」等の項目は大きなボタン(セグメントボタン)をタップして選択
4. 複数選択可能な項目は選択した分だけボタンが緑色になります
5. 数値項目は自動的に数字キーボードが開きます。日付項目は日付ピッカーが開きます
6. 「計画道路=有」など特定の回答をすると、関連する追加項目が自動的に表示されます
7. 入力は自動保存されます(数秒操作がないと自動的に保存)。手動で保存したい場合は下部の「一時保存」を押します
8. 「次へ」で次の画面へ、「戻る」で前の画面へ移動します

## 4. 写真を登録する(設備現況写真・擁壁調査共通)

1. 各写真区分のカードにある「📷 カメラで撮影」または「🖼 写真から選択」をタップ
2. 撮影/選択した写真は自動的に圧縮されてサムネイル表示されます
3. サムネイルをタップすると拡大表示・コメント入力・回転・撮り直し・順序変更・PDF掲載切替・削除ができます
4. 撮影上の注意事項が各区分の上部に表示されるので確認してから撮影してください

## 4-2. 付帯設備表を入力する

1. 目次から「④付帯設備表」をタップします
2. 「給湯関係」「キッチン設備」などの見出しをタップすると、その中の設備が開きます
3. 設備ごとに「有／無」を選び、必要に応じて下の選択肢(複数選択可)をタップします
   - もう一度押すと選択を取り消せます
4. 「判明している故障・不具合の具体的内容(自由記載)」はすべての設備にあります。
   不具合があるものだけ記入してください
5. 「備考」は2か所あります。それぞれ別の欄として保存されます

※「①役所調査」「②物件調査」「③物件状況」は現在、大項目名のみの表示です(内容は今後追加)。

## 5. 擁壁調査を入力する(擁壁がある場合)

1. 「周辺環境」画面で「擁壁の有無」を「有」にすると擁壁調査が入力対象になります
2. 「擁壁調査」画面で「＋ 擁壁を追加」をタップすると1件分の入力欄が追加されます
3. 擁壁が複数ある場合は繰り返し「擁壁を追加」で追加してください
4. 「不具合箇所を追加」でクラック等の不具合を複数登録できます。不具合を登録した場合は写真登録が必須です

## 6. 入力内容を確認する

1. 「入力内容確認」画面で修正必須のエラーと警告が一覧表示されます
2. 項目をタップすると該当画面にジャンプします
3. エラーがすべて解消されるとPDFプレビューに進めます(警告のみの場合はチェックを入れることで進めます)

## 7. PDFを出力する

1. 「PDFプレビュー」画面で自動的にPDFが生成されプレビュー表示されます
2. 「端末へ保存」で端末にPDFファイルを保存します(この操作で案件は「完了」ステータスになります)
3. 「印刷」でプリンターへ印刷、「共有」でメール等へ共有できます(共有非対応の端末では保存をご利用ください)
4. 内容を修正した場合は「再出力」で最新の内容でPDFを作り直せます

## 8. 案件を再編集・複製・削除する

- 案件一覧の各案件をタップすると、物件基本情報から再編集できます(既存の入力内容・写真は保持されます)
- 「複製」で入力内容・写真・擁壁調査を含めて別案件としてコピーできます
- 「削除」は確認ダイアログの後、案件・入力内容・写真・擁壁調査・操作履歴がすべて削除されます(元に戻せません)

## 9. データを書き出す・取り込む(機種変更・バックアップ)

調査データは端末の中だけに保存されます。次の場合はデータが引き継がれないため、事前の書き出しが必要です。

- 機種変更するとき
- アプリの置き場所(URL)が変わるとき
- ブラウザのサイトデータを削除するとき

### 書き出し
1. 「設定」画面 →「データの書き出し・取り込み」
2. 「**全案件を書き出す(写真を含む)**」をタップ
3. iPhoneでは共有メニューが開くので「**ファイルに保存**」を選び、保存先を指定します
   - 案件一覧の各案件にある「書き出し」からは、その案件だけを書き出せます

### 取り込み
1. 移行先の端末・URLでアプリを開く
2. 「設定」画面 →「**ファイルから取り込む**」をタップ
3. 書き出したファイルを選ぶ
4. 確認ダイアログで「OK」

**取り込みで既存の案件が消えることはありません。** 同じ案件が既にある場合は、上書きせずに
「(取込)」を付けた別案件として追加します。

### 運用上のおすすめ
- 調査完了時はPDFを出力し、あわせて定期的(週1回など)に全案件を書き出して保管する
- 書き出したファイルには売主情報・写真がそのまま含まれます。**保管場所の取り扱いにご注意ください**

## 10. 設定

- 「設定」画面で、写真原本の保持有無、簡易PINロックの設定/解除ができます
- PINを設定すると15分操作がない場合に自動的にロックされ、PIN入力が必要になります
