# iPhoneで使えるようにする手順

## 前提: なぜ「公開」が必要なのか

iPhoneのホーム画面にアプリとして追加するには、アプリのファイルが
**https:// で始まるURL** に置かれている必要があります(iPhoneの中に直接入れることはできません)。

つまり手順は次の2段階です。

1. アプリのファイルをHTTPSのどこかに置く(=公開する) ← **一度だけ必要な作業**
2. iPhoneのSafariでそのURLを開き「ホーム画面に追加」 ← 使う人がそれぞれ行う

---

## 1. どこに置くか(3つの選択肢)

| | 方法 | 費用 | 誰が開けるか | 手間 |
|---|---|---|---|---|
| **A** | **GitHub Pages** | 無料(※リポジトリを公開設定にする場合) | URLを知っている人は誰でも | GitHubで設定を2箇所押すだけ。以後は自動更新 |
| **B** | **社内Webサーバー / レンタルサーバー** | 既にあるなら無料 | 社内限定にできる | ファイルをアップロードするだけ |
| **C** | Netlify / Cloudflare Pages | 無料 | URLを知っている人は誰でも(Cloudflare Accessを使えば社員限定にできる) | アカウント作成が必要 |

### 判断のポイント: 何が外に見えるのか

どの方法でも **調査データ・写真・売主情報が外部に出ることはありません**。
入力内容はすべてスマートフォンの中だけに保存され、サーバーには一切送信されない作りだからです。

公開した場合に第三者が見られるのは **「空っぽの調査フォーム」** だけです。
ただしその中には、御社の調査項目・チェック項目の構成(＝業務ノウハウ)が含まれます。
これを社外の人が見られる状態にしてよいかどうかが判断の分かれ目です。

- 業務ノウハウを外に出したくない → **B(社内サーバー)** または **C＋アクセス制限**
- まず試したい・気にしない → **A(GitHub Pages)** が最短

> 補足: GitHub Pagesは、リポジトリを非公開のままにする場合でも有料プラン(GitHub Pro 月額約4ドル)が必要で、
> かつ**公開されたサイト自体は誰でも閲覧できます**(URLを知られると開けます)。
> 「サイトを非公開にする」機能は法人向けの上位プランのみです。

## 2-A. GitHub Pagesで公開する手順(最短)

このリポジトリには公開用の自動設定(`.github/workflows/deploy-pages.yml`)を用意済みです。
以下を行うと、**以後はmainブランチが更新されるたびに自動で最新版が公開されます**。

1. リポジトリを公開設定にする(無料プランの場合)
   - GitHubでリポジトリを開く → `Settings` → 一番下の `Danger Zone`
   - `Change repository visibility` → `Change to public`
2. Pagesを有効にする
   - `Settings` → 左メニューの `Pages`
   - `Build and deployment` の `Source` を **`GitHub Actions`** に変更
3. 公開を実行する
   - 上部の `Actions` タブ → 左の「不動産現地調査PWAを公開(GitHub Pages)」
   - `Run workflow` → `Run workflow` を押す(初回のみ。以後は自動)
4. 数分待つと、次のURLで開けるようになります

   ```
   https://onihei5056.github.io/-/
   ```

   (クアルトゲームは `https://onihei5056.github.io/-/quarto/` に残ります)

## 2-B. 社内サーバー / レンタルサーバーに置く手順

1. パソコンで次を実行してファイルを作ります(または本セッションからお渡ししたZIPを使用)

   ```bash
   cd app
   npm install
   npm run build
   ```

2. `app/dist` フォルダの**中身をすべて**、サーバーの公開フォルダにアップロードします
   - 例: `public_html/survey/` にアップロード → `https://自社ドメイン/survey/` で開けます
   - サブフォルダでもそのまま動きます(特別な設定は不要です)
3. **必ずHTTPS(`https://`)でアクセスできることを確認してください**
   - `http://` ではホーム画面追加もオフライン機能も動きません

## 3. iPhoneでホーム画面に追加する(利用者が行う手順)

1. **Safari** で上記URLを開く(Chromeなど他のブラウザでは追加できません)
2. 画面下部の **共有ボタン**(□に↑のアイコン)をタップ
3. メニューを下にスクロールして **「ホーム画面に追加」** をタップ
4. 右上の **「追加」** をタップ
5. ホーム画面のアイコンから起動する

初回起動時にアプリ内でも同じ案内が表示されます(「今後表示しない」で消せます)。

### Androidの場合
Chromeで開くと画面下部に「アプリをホーム画面に追加」の案内が出るので、「インストール」をタップします。

## 4. iPhoneで使ううえでの注意点

| 項目 | 内容 |
|---|---|
| **必ずホーム画面から起動する** | Safariのタブのまま使い続けると、OSが保存データを削除する場合があります。ホーム画面に追加した状態が最も安全です |
| **データ保護の確認** | アプリの「設定」画面で「データの保存状態」が **✓保護されています** になっているか確認してください。未保護の場合は同画面のボタンで要求できます |
| **調査完了後は必ずPDF出力** | データはスマートフォン内にのみ保存されます。PDFを出力して共有ドライブ等に保存することが、実質的なバックアップになります |
| **Safariのデータ削除に注意** | 設定アプリの「Safari」→「履歴とWebサイトデータを消去」を行うと、**入力済みのデータも消えます** |
| **カメラの許可** | 初回の写真撮影時にカメラの使用許可を求められます。「許可」を選んでください |
| **オフラインでも使える** | 一度開いておけば、電波の無い現地でも起動・入力・写真登録ができます。PDF出力も可能です |
| **機種変更時** | データは端末から端末へ自動では移りません。機種変更前に全案件のPDFを出力してください |

---

## 5. 更新した場合

- **GitHub Pages(A)の場合**: mainブランチを更新すれば自動で反映されます。
  利用者のiPhoneには「新しいバージョンがあります」と表示されるので「更新する」をタップします
- **自社サーバー(B)の場合**: 再度 `npm run build` して `app/dist` の中身を上書きアップロードします

更新してもスマートフォン内の調査データは消えません。
