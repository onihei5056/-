# -

このリポジトリには複数の独立したプロジェクトが含まれています。

- `index.html` … クアルト(Quarto)ボードゲーム(既存プロジェクト)
- `app/` … 不動産現地調査PWA(セットアップ・配置手順は `app/README.md` を参照)
- `docs/` … 不動産現地調査PWAの設計ドキュメント一式(Excel分析結果、項目定義書、DB設計、テスト項目等)
- `room-visualizer/` … AI部屋イメージ生成ツール「Room Visualizer」(モック版。起動方法は `room-visualizer/README.md` を参照)
