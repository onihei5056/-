# ブレインマップ

シンプルなマインドマップ（ブレインマップ）作成アプリです。`index.html` を開くだけで動作します（ビルド不要）。

## 主な機能

- ノードの追加（子・兄弟）／編集／削除
- ドラッグでノード移動、背景ドラッグでパン、ホイール／ピンチでズーム
- ブランチごとの色分け、折りたたみ表示
- ローカルストレージへの自動保存
- JSON形式での書き出し／読み込み

## 使い方

- ノードをタップして選択すると下部にアクションバーが表示されます
- 選択中に `Tab` で子ノード追加、`Enter` で兄弟ノード追加、`Delete` で削除、`F2` で編集
